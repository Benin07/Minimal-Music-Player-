# 🎵 Minimal Music Player

A lightweight, no-frills desktop music player built with **Python**, **Tkinter**, and **pygame**. Pick a folder of MP3s and hit play — that's the whole philosophy.

## ✨ Features

- 📂 **Folder-based library** — point the player at any folder and it auto-loads all `.mp3` files
- ▶️ **Essential controls** — play, pause, next, and previous with clean icon buttons
- 🎼 **Playlist view** — all tracks listed in a simple, readable listbox
- 🖱️ **Menu bar access** — load your music folder from the `organise` menu
- 🪶 **Minimal footprint** — one Python file, zero bloat

## 🛠️ Tech Stack

| Component | Purpose |
|---|---|
| `tkinter` | GUI window, listbox, buttons, menus |
| `pygame.mixer` | Audio loading and playback |
| `os` | Folder scanning & file paths |
